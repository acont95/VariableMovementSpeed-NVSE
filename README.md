# Variable Movement Speed NVSE

**Variable Movement Speed NVSE** is a plugin for **xNVSE (New Vegas Script Extender)** meant for use with my 
[VariableMovementSpeed](https://www.nexusmods.com/newvegas/mods/97723) mod. This plugin applys an isolated walk speed
multiplier read from a global var form to the walk speed calculation function, in a similar way to the running speed perk entry point. 
This bypasses issues with trying to share the SpeedMult actor value with walk and run states.
